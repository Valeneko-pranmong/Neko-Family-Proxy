# คู่มือการใช้งาน Neko Control

คู่มือนี้ใช้สำหรับผู้ดูแลระบบ Neko Family Proxy ในการจัดการสมาชิก สิทธิ์ใช้งาน
คูปอง และเซสชันออนไลน์

## เริ่มต้นใช้งาน

1. เปิดหน้า Neko Control และเข้าสู่ระบบด้วยบัญชีผู้ดูแล
2. บัญชีที่เข้าใช้งานต้องอยู่ใน `ADMIN_EMAIL_ALLOWLIST` และมีบทบาท
   `admin` ที่สถานะ `active` ใน Supabase
3. หากเห็นแถบ “กำลังแสดงข้อมูลตัวอย่าง” แปลว่ายังไม่ได้ตั้งค่า Supabase
   ฝั่งเซิร์ฟเวอร์ หน้าเว็บจะยังแสดงข้อมูลตัวอย่างและไม่อนุญาตให้ทำรายการจริง
4. ใช้ช่องค้นหาด้านบนเพื่อค้นหาสมาชิก อีเมล ชุดคูปอง หรือสถานะ
5. กด “คู่มือการใช้งาน” บนแถบด้านบนเพื่อเปิดคู่มือออนไลน์

## เมนูภาพรวม

ใช้ตรวจสอบจำนวนสมาชิก สิทธิ์ใช้งาน เซสชันออนไลน์ และคูปองที่ยังไม่ถูกใช้
กราฟกิจกรรมช่วยให้เห็นแนวโน้มการเชื่อมต่อ ส่วนกิจกรรมล่าสุดใช้ตรวจสอบเหตุการณ์
ด้านความปลอดภัยและสิทธิ์

## เมนูสมาชิก

- ค้นหาด้วยชื่อ อีเมล หรือสถานะ
- ใช้ปุ่ม “ระงับสมาชิก” เมื่อต้องหยุดการใช้งานบัญชี
- ใช้ปุ่มเดิมเพื่อ “เปิดใช้งานสมาชิก” หลังตรวจสอบเรียบร้อย
- ตรวจสอบบทบาทก่อนแก้ไขสถานะทุกครั้ง

## เมนูสิทธิ์ใช้งาน

- ตรวจสอบผลิตภัณฑ์ วันหมดอายุ และจำนวนอุปกรณ์
- กด “ต่ออายุ 30 วัน” เมื่อต้องเพิ่มระยะเวลาให้สมาชิก
- กด “ยกเลิกสิทธิ์ใช้งาน” เมื่อมีเหตุผลด้านการชำระเงินหรือความปลอดภัย
- บันทึกเหตุผลการแก้ไขไว้ในระบบหรือช่องทางภายในของทีม

## เมนูคูปอง

1. กด “สร้างชุดคูปอง”
2. เลือกผลิตภัณฑ์ ระบุจำนวนวันใช้งาน และจำนวนรหัส
3. เพิ่มวันหมดอายุของรหัสหากต้องการจำกัดช่วงเวลา
4. ใส่หมายเหตุภายใน เช่น ชื่อลูกค้า แคมเปญ หรือเลขอ้างอิง
5. กด “สร้างรหัส”
6. กด “คัดลอกรหัส” แล้วส่งให้ลูกค้าผ่านช่องทางส่วนตัว

รหัสคูปองจะแสดงเพียงครั้งเดียว ระบบจัดเก็บเฉพาะค่าแฮชและไม่สามารถเปิดดู
plaintext เดิมภายหลังได้ หากรหัสรั่วไหลให้ยกเลิกชุดคูปองทันที

## เมนูเซสชันออนไลน์

ใช้ตรวจสอบอุปกรณ์ที่มีการส่ง heartbeat ล่าสุด หากพบอุปกรณ์หรือบัญชีที่ไม่รู้จัก
ให้กด “ยกเลิกเซสชัน” ระบบจะบังคับให้เครื่องนั้นเข้าสู่ระบบใหม่

## เมนูประวัติการใช้งาน

ใช้ตรวจสอบเหตุการณ์ เช่น การสร้างคูปอง การเปลี่ยนสิทธิ์ การระงับสมาชิก และการ
ยกเลิกเซสชัน ควรตรวจสอบเมนูนี้เมื่อมีข้อร้องเรียนหรือพบพฤติกรรมผิดปกติ

## ข้อควรระวัง

- ห้ามใส่ Supabase secret key ในโค้ดฝั่ง Browser หรือไฟล์ที่ commit ขึ้น GitHub
- ห้ามส่งคูปองในห้องแชตสาธารณะ
- ห้ามแก้ไขสิทธิ์ Admin ให้บัญชีที่ยังไม่ผ่านการตรวจสอบ
- ไม่ควรลบข้อมูลเพื่อแก้ปัญหา ให้ใช้คำสั่งระงับ ยกเลิก หรือ revoke ก่อน
- หากพบเหตุการณ์ผิดปกติ ให้เก็บอีเมล เวลา อุปกรณ์ และรายการใน Audit log
  เพื่อให้ทีมตรวจสอบต่อได้
