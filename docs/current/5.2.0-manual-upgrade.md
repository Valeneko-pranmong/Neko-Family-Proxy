# Neko Family Proxy 5.1.6 → 5.2.0 Manual Upgrade

**Why this is manual:** v5.2.0 rotates the Ed25519 release key and the profile-authority key. A 5.1.6 installation contains an update profile that trusts only `neko-update-prod-1`; the custody material for that key is no longer available, so no transitional release can be signed for automatic delivery. The 5.2.0 installer replaces the installed profile with one signed by `neko-update-profile-v520-1` and authorizing `neko-update-prod-2`.

## Before you start

- Download only from the canonical repository releases page: `Valeneko-pranmong/Neko-Family-Proxy/releases`.
- Close Neko Family Proxy, any active proxy session, and PSO2.
- Your account/session files and preferences live under `%LOCALAPPDATA%\NEKO FAMILY`. The installer is designed to preserve them; do not delete that directory.
- Authenticode signing is not yet available in 5.2.0. If the release publishes SHA-256 values, compare them before running the installer.

## Steps

1. Download `NekoFamilyProxy-Installer.exe` from the 5.2.0 release.
2. Run the installer and allow it to install over the existing `%LOCALAPPDATA%\NEKO FAMILY` installation.
3. If Windows asks for elevation for the NetFilter driver step, approve it. The elevated helper verifies pinned Core/driver hashes and loads declared DLLs from an administrator-only staging directory.
4. Start Neko Family Proxy.
5. Open Settings > About and confirm `Version / Build: v5.2.0`.
6. Sign in and start PSO2 through the normal flow.

After this first manual install, the 5.2.x line can use the normal deferred automatic update path again.

## Do not do this

- Do not replace only `NekoLauncher.exe` or `NekoUpdater.exe` by hand. The trust profile is installed by the setup program and must match the new binaries.
- Do not keep a pre-5.2.0 `trust/update-profile-v1.json` in the install directory. The installer replaces it; a stale profile will cause the new client to reject valid 5.2.x releases.
- Do not downgrade to 5.1.6 by copying old files after installing 5.2.0. The installed profile will no longer be accepted by the old client. If you must return to 5.1.6, use a full uninstall/reinstall and expect the old update path to be unavailable.
- Do not share or upload private key files; only public keys and signed release metadata are public.

## Troubleshooting

| Symptom | Action |
| --- | --- |
| About still shows 5.1.6 | Close all Launcher processes and run the 5.2.0 installer again. |
| Update check fails after manual install | Confirm `trust/update-profile-v1.json` exists under the install root and the version is 5.2.0. Re-run the installer if the profile is missing. |
| Driver step fails | Re-run the installer with elevation and check that the pinned driver files were not modified or quarantined by antivirus. |
| Installer blocked by SmartScreen | 5.2.0 is not Authenticode-signed yet. Verify the download source and published SHA-256 before choosing to run it. |

## Support information

When reporting an installation problem, include:

- Current version shown in Settings > About
- Whether the 5.2.0 installer completed or was rolled back
- The support log path under `%LOCALAPPDATA%\NEKO FAMILY\logs`
- The exact error text from the installer or Launcher

Do not include passwords, session tokens, or private key material in support reports.
