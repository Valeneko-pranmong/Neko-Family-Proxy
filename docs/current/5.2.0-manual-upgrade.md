# Neko Family Proxy 5.1.6 -> 5.2.0a1: Separate Installation Lines

**Status:** policy updated 2026-10-25. The 5.2.0 preview line is re-versioned
as `5.2.0a1` for alpha testing. The uninstall/process guard is implemented in
installer source, but the rebuilt installer and install/uninstall matrix are
not verified yet; do not publish or distribute 5.2.0a1 until the guard,
web-only login, and E2E gates pass. See
`docs/superpowers/plans/2026-10-25-web-auth-separation-and-5-3-0-cutover.md`.

## Why this is not an in-place upgrade

v5.1.6 and v5.2.0a1 use different authentication and trust lines:

- v5.1.6 keeps password/recovery login and the legacy backend.
- v5.2.0a1 is a **web-auth-only** line using an isolated schema/RPC namespace in
  the same Supabase project. The `auth.users` pool is shared until 5.3.0.
- v5.1.6 cannot auto-update to v5.2.0a1 because the release trust anchors rotate.
- Installing v5.2.0a1 over v5.1.6, or keeping both installed, is not supported.

## Choose one line

- **Stay on 5.1.6** if you need the current service during 5.2.0 development.
  No action is required, and 5.1.6 remains usable until the 5.3.0 cutover.
- **Move to 5.2.0a1** only after the alpha test notes say the installer and
  bridge are ready: uninstall 5.1.6 first, then install 5.2.0a1. The 5.2.0a1
  alpha is for **new accounts only**; it does not migrate a 5.1.6 account.
- **If you still need remaining days on your 5.1.6 account**, stay on 5.1.6
  until the existing term expires or an announced cutoff. There is no day or
  coupon transfer to 5.2.0a1. Do not uninstall it for 5.2.0a1.

## Before you start

- Close Neko Family Proxy, any active proxy session, and PSO2.
- Back up any local preferences you need. The current uninstaller removes
  launcher state, trust, baseline, tools, ProxyCore, logging, `*.json`, and
  `*.path` files from `%LOCALAPPDATA%\NEKO FAMILY`; do not assume settings are
  preserved across the line separation.
- Your 5.1.6 account remains on the legacy backend. 5.2.0a1 will not import it,
  and there is no day/coupon transfer; do not uninstall 5.1.6 if you still
  need its remaining term.
- Download only from the canonical repository releases page:
  `Valeneko-pranmong/Neko-Family-Proxy/releases`.
- Authenticode signing is still pending. If SHA-256 values are published,
  compare them before running the installer.

## Steps for starting a new 5.2.0a1 account

1. Confirm that the 5.2.0a1 alpha notes say the uninstall guard and
   web-only login are available. Do not use an older candidate.
2. Uninstall **NEKO FAMILY PROXY 5.1.6** from Windows Settings > Apps >
   Installed apps.
3. Confirm the 5.1.6 installation is gone. If the uninstaller reports a
   failure, resolve it before continuing; do not force-install 5.2.0a1 over a
   partial 5.1.6 tree.
4. Run the 5.2.0a1 installer. It must refuse to install if it finds a 5.1.6
   installation or a running Launcher/Core process.
5. Start Neko Family Proxy and create/sign in to a new 5.2.0a1 account through
   the Discord browser flow. There is no password login in 5.2.0a1, and a 5.1.6
   account is not accepted.
6. Open Settings > About and confirm `Version / Build: v5.2.0a1`.
7. Start PSO2 through the normal flow.

The shared netfilter2 driver is intentionally preserved by uninstall and is
reused by the next installation.

## Do not do this

- Do not install 5.2.0a1 over 5.1.6.
- Do not keep 5.1.6 and 5.2.0a1 installed at the same time.
- Do not manually copy an old `trust/update-profile-v1.json`, state, or
  credentials into 5.2.0a1.
- Do not replace only `NekoLauncher.exe` or `NekoUpdater.exe` by hand.
- Do not downgrade by copying old files after installing 5.2.0a1. A downgrade
  requires a full uninstall/reinstall and is not a data-preserving path.
- Do not share or upload private key files, passwords, or session tokens.

## Troubleshooting

| Symptom | Action |
| --- | --- |
| Installer says 5.1.6 is still installed | Uninstall 5.1.6 through Windows Settings > Apps, then retry. |
| Installer says Launcher or Core is running | Close Neko Family Proxy, the proxy session, and PSO2, then retry. |
| Uninstall fails or leaves a partial tree | Stop and contact the operator; do not force-install 5.2.0a1 over the partial tree. |
| About still shows 5.1.6 | You are running the old line. Confirm which executable/shortcut you launched. |
| Discord login does not open | Confirm the 5.2.0a1 alpha is built with the bridge enabled and check the alpha test notes. |
| Driver step fails | Re-run the installer with elevation and check that antivirus did not quarantine the pinned driver files. |
| Installer blocked by SmartScreen | 5.2.0a1 is not Authenticode-signed yet. Verify the download source and published SHA-256 before running it. |

## Support information

When reporting an installation problem, include:

- Current version shown in Settings > About
- Whether the 5.1.6 uninstall completed
- Whether the 5.2.0a1 installer completed or was rolled back
- The support log path under `%LOCALAPPDATA%\NEKO FAMILY\logs`
- The exact error text from the installer or Launcher

Do not include passwords, session tokens, identity tokens, or private key
material in support reports.
