# Neko Family Proxy 5.1.6 -> 5.2.0 Manual Upgrade

**Status:** PREVIEW BUILD READY — NOT PUBLISHED. The unsigned 5.2.0 preview
installer and install/rollback matrix are recorded; interactive Discord
login/Core start and owner sign-off remain before this guide can be
distributed as a release instruction.

**Policy:** clean uninstall-first (owner decision, 2026-10-25). 5.1.6 and
5.2.0 are separate installation lines. In-place upgrade and side-by-side
installation are not supported. 5.1.6 remains the frozen fallback and keeps
working on its existing password/recovery backend.

## Why this is not an in-place upgrade

- 5.1.6 uses the legacy password/recovery backend and its existing trust
  profile.
- 5.2.0 uses Neko-NETWORK-ID Discord login and Neko Proxy API. The Launcher
  stores an identity refresh token in Windows Credential Manager and never
  reads the legacy Supabase session.
- The installer deliberately blocks installation over 5.1.6 so that mixed
  program, trust, and local state cannot occur.
- 5.2.0 is not delivered as an automatic update to 5.1.6.

## Choose one line

- **Stay on 5.1.6** if you still need the current service or remaining days.
  No action is required. There is no day, license, or coupon transfer to
  5.2.0.
- **Move to 5.2.0** only after the release notes announce that installation is
  allowed. Back up local preferences, uninstall 5.1.6, then install 5.2.0 as a
  clean installation. A 5.1.6 account is not migrated into 5.2.0.
- **If you need the remaining 5.1.6 term**, stay on 5.1.6 until it expires or
  an announced cutoff is reached. Do not uninstall it for 5.2.0.

## Before you start

- Close Neko Family Proxy, any active proxy session, and PSO2.
- Back up any local preferences you need. Uninstalling 5.1.6 removes launcher
  state, trust, baseline, tools, ProxyCore, logging, and local `*.json` and
  `*.path` files from `%LOCALAPPDATA%\NEKO FAMILY`.
- Download only from the canonical repository releases page:
  `Valeneko-pranmong/Neko-Family-Proxy/releases`.
- 5.2.0 has no Authenticode signature. If SHA-256 values are published, compare
  them before running the installer.

## Steps for a clean 5.2.0 installation

1. Confirm that the release notes say the 5.2.0 staging E2E, installer build,
   and install matrix have passed. Do not use an older candidate.
2. Uninstall **NEKO FAMILY PROXY 5.1.6** from Windows Settings > Apps >
   Installed apps.
3. Confirm the 5.1.6 installation is gone. If the uninstaller reports a
   failure, stop and resolve it; do not force-install 5.2.0 over a partial
   tree.
4. Run the approved 5.2.0 installer. It must refuse to install if it finds a
   running Launcher/Core/Updater process or a remaining installation with a
   different version.
5. Start Neko Family Proxy and sign in through the Discord browser flow.
   There is no password login in 5.2.0.
6. Open Settings > About and confirm `Version / Build: v5.2.0`.
7. Start PSO2 through the normal flow.

The shared netfilter2 driver is intentionally preserved by uninstall and is
reused by the next installation.

## What is preserved and what is lost

| Item | 5.1.6 -> 5.2.0 clean install |
| --- | --- |
| netfilter2 driver | Preserved (shared machine prerequisite). |
| Launcher state, preferences, logs | Removed by the 5.1.6 uninstall. |
| 5.1.6 trust and baseline files | Removed; 5.2.0 enrolls its own trust profile. |
| 5.1.6 account, remaining days, coupons | Stay on the legacy backend; no transfer. |
| 5.1.6 Supabase/bridge session | Not read, not migrated, not preserved. |
| 5.2.0 identity refresh token | Created only after a successful Discord login. |

## Rollback to 5.1.6

1. Uninstall 5.2.0. Its local state, trust, baseline, logs, and program files
   are removed.
2. Install the frozen 5.1.6 installer from the canonical release source.
3. Sign in with the 5.1.6 account credentials.
4. Do not copy 5.2.0 tokens, trust files, or state into the 5.1.6 installation.

Rollback is a clean reinstall. It does not restore 5.2.0 local preferences and
does not transfer 5.2.0 state back to 5.1.6.

## Do not do this

- Do not install 5.2.0 over 5.1.6.
- Do not keep 5.1.6 and 5.2.0 installed at the same time.
- Do not manually copy an old `trust/update-profile-v1.json`, state, or
  credentials into 5.2.0.
- Do not replace only `NekoLauncher.exe` or `NekoUpdater.exe` by hand.
- Do not downgrade by copying old files after installing 5.2.0.
- Do not share or upload private key files, passwords, refresh tokens, or
  session tokens.

## Troubleshooting

| Symptom | Action |
| --- | --- |
| Installer says a different version is still installed | Uninstall the existing version through Windows Settings > Apps, then retry. |
| Installer says Launcher or Core is running | Close Neko Family Proxy, the proxy session, and PSO2, then retry. |
| Uninstall fails or leaves a partial tree | Stop and contact the operator; do not force-install 5.2.0 over the partial tree. |
| About still shows 5.1.6 | You are running the old line. Confirm which executable and shortcut you launched. |
| Discord login does not open | Confirm the 5.2.0 build was made with the approved Proxy API and identity configuration. |
| Driver step fails | Re-run the installer with elevation and check that antivirus did not quarantine the pinned driver files. |
| Installer blocked by SmartScreen | 5.2.0 is not Authenticode-signed. Verify the download source and published SHA-256 before running it. |

## Support information

When reporting an installation problem, include:

- the version shown in Settings > About;
- whether the 5.1.6 uninstall completed;
- whether the 5.2.0 installer completed or was rolled back;
- the support log path under `%LOCALAPPDATA%\NEKO FAMILY\logs`;
- the exact error text from the installer or Launcher.

Do not include passwords, refresh tokens, identity tokens, permits, runtime
credentials, or private key material in support reports.
