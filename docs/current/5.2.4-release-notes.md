**Release line:** v5.2.4 (public stable; `releases/latest` after live apply)
**Date:** 2026-10-28
**Channel:** stable envelope
**Trust profile:** `trust/update-profile-v1.json` (`neko-update-profile-v520-2`, channel `stable`)
**Release envelope:** `stable-0030`, sequence 30, `minimum_supported_sequence = 30`
**Signing key:** `neko-update-prod-3` (Ed25519)
**Authenticode:** not applied (operator certificate still pending)

## Summary

5.2.4 fixes the production sign-in failure in 5.2.3. The frozen build was
pinned to the staging Proxy API and identity origins, and it sent the legacy
`neko-launcher` OAuth client, so the live identity service rejected the
sign-in with `identity_not_linked`.

A 5.2.3 installation (re-release with updater `b0b991f5…`) **updates
automatically** to 5.2.4. No reinstall is required. Old 5.2.2 and the first
5.2.3 build cannot auto-update and still need the manual installer.

## Customer-visible changes

- Discord sign-in works against the production identity service; the first
  login provisions a pending proxy account and shows **0 days** until a
  coupon is redeemed.
- Coupon redemption in Settings activates the account and adds days without a
  manual link or admin approval.
- `NEKO FAMILY NETWORK ID` remains the read-only brand dashboard; it does not
  gate launcher access.
- Existing 5.2.3 refresh tokens belong to the legacy client profile, so the
  first 5.2.4 launch signs the user in with Discord once more.
- No change to ProxyCore, the proxy connection, or the PSO2 game flow.
