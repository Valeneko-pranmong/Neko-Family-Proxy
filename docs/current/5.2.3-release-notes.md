## Summary

5.2.3 fixes the first-login failure where a Discord identity without a
pre-linked proxy account received "บัญชี Discord นี้ยังไม่ได้เชื่อมกับบัญชี
Neko Family". The launcher now signs in, shows zero days, and lets the user
activate proxy days with a coupon from Settings.

There is no change to ProxyCore, the runtime proxy connection, or the PSO2
game flow.

## Customer-visible changes

- Discord login works on first use. The proxy account is provisioned as
  `pending` by the Neko Proxy API; no manual link step is required.
- An account without an activated coupon signs in with **0 days** and cannot
  start the proxy until a coupon is redeemed.
- Coupon redemption in Settings now calls `POST /v1/coupons/redeem`; a
  successful redemption activates the account, adds the days, and refreshes
  the claimed session.
- `NEKO FAMILY NETWORK ID` keeps the same Discord login. The
  `neko-family-proxy` app is public, so an app-role grant is not required
  before login.

## Upgrade behavior

- The envelope sets `minimum_supported_sequence = 27`, so 5.2.2 and older
  preview/stable installs are expected to update before using the new line.
- An active game or proxy session is not force-closed by the updater.
- The installer remains clean-install-first for 5.1.6; there is no legacy
  day/coupon transfer.

## Server prerequisites

The login/coupon behavior depends on two SQL migrations:

1. Proxy project `miikoutrnxsunbndecqh`:
   `20261028120000_proxy_self_service_provisioning.sql`
2. Identity project:
   `20261028120000_open_launcher_app_access.sql`

Apply them before deploying the updated Neko Proxy API and identity build.
