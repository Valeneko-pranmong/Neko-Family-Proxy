## Summary

5.2.3 contains the self-service Discord login and coupon fixes, plus the
updater fix required to make in-app updates work again.

A 5.2.2 installation **cannot auto-update to 5.2.3**. Those users must run the
5.2.3 installer once (uninstall the old version first). After that, future
5.2.x updates work normally.

## Why the first 5.2.3 release could not update 5.2.2

Three layers blocked the update:

1. The launcher compares the installed `NekoUpdater.exe` with the incoming
   release. The 5.2.2 helper (`35f4532c…`) does not match the original 5.2.3
   helper, so discovery ended with `UPDATER_INCOMPATIBLE`.
2. After pinning the manifest to the installed helper, the live apply still
   failed with `CORE_INVENTORY_INVALID`: the 5.2.2 updater validates the
   installed Core with the canonical manifest schema
   (`rid` / `executable` / `files[]`), while the frozen 5.2.0 Core authority
   uses the legacy schema (`file_count` + path → SHA-256 map).
3. After the inventory fix, probation still ran the frozen Core's
   `--update-preflight`; the 5.2.0 Core predates that flag and exits 2, so the
   apply aborted with `SELFTEST_FAILED`.

The Core checks run inside `NekoUpdater.exe`, and the update pipeline never
stages or replaces the updater, so a feed change cannot fix them.

This re-release rebuilds the updater with support for both Core manifest
schemas, skips the unsupported preflight for the frozen Core while keeping the
full 1,023-file inventory check, and pins its bytes (`b0b991f5…`) for the rest
of the 5.2.x line. The old 5.2.3 release was withdrawn while the fix was
prepared; this build uses sequence 28 because any machine that attempted the
broken release recorded sequence 27 as failed.

## Customer-visible changes

- Discord login works on first use; a pending proxy account shows **0 days**
  until a coupon is redeemed.
- Coupon redemption in Settings calls `POST /v1/coupons/redeem`, activates the
  account, adds days, and refreshes the session.
- `NEKO FAMILY NETWORK ID` keeps the same Discord login; no app-role grant is
  required first.
- No change to ProxyCore, the proxy connection, or the PSO2 game flow.

## Manual migration from 5.2.2 / old 5.2.3

1. Close Neko Family Proxy, the proxy session, and PSO2.
2. Uninstall the old version from **Windows Settings > Apps > Installed apps**.
3. Download `NekoFamilyProxy-Installer.exe` from the v5.2.3 release.
4. Run the installer and wait for the Core and .NET steps.
5. Open the launcher and sign in with Discord again.
6. Confirm Settings shows **5.2.3** and
   `%LOCALAPPDATA%\NEKO FAMILY\baseline\release-v2.json` is the `stable-0028`
   envelope.

Account days and entitlement are stored on the server; uninstalling does not
remove them. The local Windows Credential Manager entry is removed by the
uninstaller, so the Discord sign-in is required again.
