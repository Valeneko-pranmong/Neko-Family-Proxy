## 1. Changes

### Login
- Title and primary button now read `ล็อคอินด้วย Neko Family Network ID`.
- The button carries the bundled Discord icon (`Asset/discord-icon-svgrepo-com.png`).
- The welcome copy is `ยินดีต้อนรับสู่ Neko Family Proxy`.
- The support line is `มีปัญหาการใช้งานติดต่อ ที่ดิสคอส https://discord.gg/fkjXW9AJ6a` and opens the link.

### Window and Settings
- The main window is fixed at 500×640. Maximize and resize are disabled on
  the login, recovery, and dashboard views.
- The Settings window is laid out off-screen and shown only after the build
  completes, so its Thai labels appear in one frame instead of painting
  progressively.

### Uninstall
- The installer now refuses to uninstall while `NekoLauncher`,
  `NekoProxyCore`, or `NekoUpdater` is still running, matching the install-time
  process guard and preventing removal of `state`/program files under a live
  session.

### Login latency
- When the user starts Discord login, the Launcher pre-warms the identity
  token, `/v1/me`, and `/v1/session/claim` endpoints in parallel while the
  browser/Discord step is in progress. This removes most cold-start latency
  without changing the get_me → claim safety order or any backend behavior.

## 2. Update policy from 5.2.1

- The 5.2.1 envelope is `preview-0016`, sequence 16, `minimum_supported_sequence = 16`.
- Every later 5.2.x release must set `minimum_supported_sequence` to its own
  release sequence. A 5.2.2 release must therefore use sequence 17 and
  `minimum_supported_sequence = 17`.
- A 5.2.1 installation that sees 5.2.2 is classified as `MANDATORY_UPDATE` at
  startup, even if the envelope's `mandatory` flag is false.
- The running session is never force-closed. If the game/proxy is active, the
  update is deferred and login is blocked the next time the user opens the
  Launcher; with no active game, the startup path applies the update before
  login. This is covered by
  `test_5_2_1_to_5_2_2_is_mandatory_on_next_startup`,
  `test_5_2_2_minimum_sequence_forces_mandatory_even_without_flag`, and
  `test_active_game_blocks_update_without_stopping_proxy_or_preparing`.
